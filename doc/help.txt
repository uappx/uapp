
uapp 通用命令🔥

  - 当前目录下生成注册协议, 隐私协议
    uapp privacy

  - 新建工程
    uapp new demo1    # 使用 uapp-webapp 模版新建工程
    uapp add android  # 当前目录下创建 android 工程
    uapp add ios      # 当前目录下创建 ios 工程

  - webapp 工程下编译命令
    uapp run dev:h5
    uapp run build:mp-weixin --open # 参数 open 表示使用微信开发者工具打开
    uapp run build:app -r uapp.wgt  # 打包为 uapp.wgt

  - 使用 HBuilderX 内置 Node/Jest 自动化测试
    uapp run test:web-chrome
    uapp run test:mp-weixin
    uapp run test:app-android
    uapp run test:app-ios-simulator
    uapp run test:app-ios
    uapp run test:app-harmony

  - app 工程下命令
    uapp run build:app                # 编译并发布自定义基座到 HBuilderX 下
    uapp run build:app --release apk  # 编译 release 发布包
    uapp run build:app -r aab         # android 下打包为 aab 的格式
    uapp run build:app-plus -r apk    # 注意：vue2 要用 :app-plus

  - 配置 HBuilderX, node 和 微信安装环境
    uapp config set hbx.dir "C:\Program Files (x86)\HBuilderX"
    uapp config set wx.dir "C:\Program Files (x86)\Tencent\微信web开发者工具"
    uapp config get hbx.dir          # 读取已保存的值，未配置时返回非零退出码
    uapp config list                 # JSON 格式列出已保存配置；也可直接 uapp config
    uapp config delete hbx.dir       # 删除显式配置，恢复运行时默认探测

  - 直接用微信开发者工具内置的 cli
    uapp wx help

  - 直接用 HBuilderX 内置的 cli
    uapp hbx open
    uapp hbx help

app 工程下命令:

    uapp manifest path/to/manifest.json  # 配置 webapp 工程里的 manifest.json 位置
    uapp info                            # 显示APP开发中会用到的配置信息
    uapp keygen                          # 生成 android 的签名文件 app.keystore

  - 更新打包用到的数据，包括版本信息, dcloudkey, App图标, 本地打包资源等
    uapp prepare build:app
    uapp prepare build:app --no-webapp             # 不编译 webapp

  - 运行自定义打包发布流程，配置见 README.md
    uapp run custom
